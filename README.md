# yaju-glossary — 例のアレ語録スキル

**「例のアレ」語録を、AIエージェントが会話で常用するためのスキル（Agent Skill）。**

淫夢・クッキー☆・ヒカマニ・Syamu・チャー研・総統閣下ほか、日本語ネット文化の主要コンテンツ100超の語録1,000超を、**意味・由来・用法つき**で収録。エージェントはこれをロードすると、雑談から相槌まで「例のアレ」語録を自然に織り込んで会話するようになる。

## これは何？

「例のアレ」= 2010年代以降の日本語ネット文化圏（主にニコニコ動画発）のアンダーグラウンドミーム総称。本リポジトリは、その語録（決まり文句・名セリフ・内輪ノリの語彙）を大全化し、AIエージェントが使いこなすためのガイドとデータを提供する。

- ✅ 語録1,000超（読み・発言者・出典・意味・用法）
- ✅ 100超コンテンツ（淫夢から最新のぼざろ・シャニマスMADまで）
- ✅ 使い方の作法（TPO・密度・注意）込み
- ✅ 調査元: ニコニコ大百科 / ピクシブ百科事典 / 淫夢Wiki / クッキー☆実況wiki / チャージマン研!Wiki / ヒカマーwiki(Wayback) / 各まとめブログ

## 使い方

### Hermes Agent
```bash
hermes skills install https://github.com/maebahesioru/yaju-glossary
```

### Claude Code / Claude Desktop / その他 Agent Skills 互換環境
`skills/` ディレクトリに配置するか、`SKILL.md` を読み込ませる。

### 手動
`SKILL.md` から読み始め、必要に応じて `references/` を参照。

## 構成

```
SKILL.md                       # 本体（使い方の作法+超常用語録）
```
