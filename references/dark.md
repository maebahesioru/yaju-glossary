# 闇・削除対象系リファレンス

ネット文化の「裏側」——削除対象・アングラ・炎上の語彙集。

- **削除対象素材MAD**: ニコニコで削除されがちな素材を使ったMAD。権利者削除・運営削除との戦いの文化
- **釣り動画**: サムネと内容が違う伝統芸。荒らし文化
- **検索してはいけない言葉**: 都市伝説的な禁断ワード集
- **クソ映画**: 低予算映画を愛でる文化（サメ映画、メタルマン等）

## 各ネタの語録

低予算・低品質だが愛すべきB級映画の総称。サメ映画、メタルマン等が代表格。『クソ映画を愛でる』文化は例のアレ圏の重要な一部。

- 「クソ映画」

### 削除対象素材MAD
削除対象素材MADリンクとは、過去に権利者削除及び管理者削除された素材を複数使ったMAD作品全般に使われるタグである。

代表フレーズ・語録:
- 「削除対象素材MADリンク」
- 「ニコニコ族の削除」

**釣り** （つり）とは、「釣る」という動詞の名詞形である。主に以下の意味などで使われる。

### ランキング工作
工作(ランキング)とは、ニコニコ動画上の特定動画に表示される**再生 数・コメント数・マイリスト数**のいずれかを不正に大量増加させる行為のことである。

### エロゲ
エロゲとは、狭義には年齢制限を持つアダルトゲームのうち、その制限（一般には18禁）の主な理由が性的表現（セックスシーンなど）があるために年齢制限されるゲームのことである。

代表フレーズ・語録:

- 「TSUTAYA AVCLUB」

### 炎上動画
ネット上で炎上した動画・騒動の総称。例のアレ文化圏では炎上そのものがコンテンツとして消費・記録される。

代表フレーズ・語録:
- 「炎上動画」
- 「動画がコメで炎上している」
- 「動画の荒れ」


### 人類には早すぎる動画
人類には早すぎる動画とは、その内容があまりにも先進的すぎるため、われわれ現代の人類には理解が及ばない動画群の総称である。

代表フレーズ・語録:
- 「人類には早すぎる動画」
- 「この動画は人類には早すぎるわ」
- 「もっと評価されるべき」
- 「ギレルモ・デル・トロ」
- 「人類には早すぎる静画」
- 「人類には早すぎる」
- 「……………………え、なにこれ？」


### 検索してはいけない言葉
「**検索してはいけない言葉** 」とは、Googleをはじめとする検索サイトでグロ画像や恐怖画像などの深いトラウマを与えるであろう内容、もしくはアングラサイトやウイルスサイトにリンクしてしまう危ない検索キーワードのこと。「**ググってはいけない言葉** 」とも呼ばれる。インターネットのコミュニティ上で広まった解釈ではあるが、最近では地上波放送のバラエティ番組の題材にも使われるほど定着しているようだ。

代表フレーズ・語録:
- 「検索してはいけない言葉」
- 「検索しては～」
- 「**検索してはいけない言葉**」
- 「**ググってはいけない言葉**」
- 「実際に検索してはいけない」
- 「閲覧注意」
- 「絶対にNG」
- 「責任を負わない」
- 「危険」
- 「**怖いもの見たさで検索したい言葉**」
- 「検索してはいけない～」
- 「**うそはうそであると見抜ける人でないと(掲示板を使うのは)難しい**」
- 「ググってはいけない言葉の一覧」
- 「ほんとにあった！呪いのビデオ」
- 「探偵!ナイトスクープ」
- 「キ（サイト名）」
