# CM・商品・その他ミームリファレンス

CM・商品・企業・ゲーム等の語録集。長寿CMや独特の商品はネットミームの宝庫。

- **ヴェルタースオリジナル**: 「おいしい♪」（仮面の男）
- **ねるねるねるね**: 知育菓子。「魔法の粉」レトロCM
- **ドナルド・マクドナルド**: ドナルドのキャラクター性と奇行ムービー
- **Yee**: 恐竜の鳴き声ミーム（海外発、日本に逆輸入）
- **オンドゥル語**: 仮面ライダー剣の滑舌から生まれた言語ネタ
